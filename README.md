# Таймер 7 минут (Android)

Приложение запускает повторяющийся сигнал каждые 7 минут, пока пользователь не нажмёт «Стоп».
Сигналы доставляются через AlarmManager, поэтому приложение не обязано оставаться открытым.
После перезагрузки телефона активный таймер планирует следующий интервал заново.

## Сборка APK
1. Откройте папку `SevenMinuteTimer` в Android Studio (Giraffe или новее).
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

При первом запуске разрешите уведомления. Для максимально точных семиминутных интервалов Android также попросит разрешить точные будильники. На некоторых прошивках энергосбережение может задерживать сигналы; при необходимости разрешите приложению работу без ограничений батареи.
